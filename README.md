# Real Kanye

A responsive Kanye West themed website built as a frontend practice project.

The website focuses on Kanye's early career, his rise as a producer and artist, and some of his most influential albums.

## Live Website

https://germy08.netlify.app

## GitHub Repository

https://github.com/germy08/Real-Kanye

## About The Project

This project was created primarily to practice and improve my skills with **Tailwind CSS**.

I had recently started learning Tailwind CSS, so I wanted to build something more challenging than small practice components.

The goal was to create a visually strong website that works across both:

- Mobile devices
- Desktop / laptop screens

The website is completely static and focuses on design, layout, typography, imagery, and responsiveness.

## Technologies Used

- HTML5
- Tailwind CSS

No JavaScript was used in this project.

## What I Practiced

### Tailwind CSS

The main purpose of this project was to get a stronger grip on Tailwind CSS.

I practiced:

- Utility classes
- Responsive breakpoints
- Spacing
- Typography
- Background images
- Flexbox
- CSS Grid
- Positioning
- Sizing
- Responsive layouts

### CSS Grid

I worked extensively with CSS Grid to create structured layouts for different sections of the website.

### Flexbox

The project also helped me strengthen my understanding of Flexbox and how it can be combined with Grid to create responsive layouts.

### Responsive Design

The website was designed to adapt to different screen sizes, including mobile phones and laptops/desktops.

### HTML

Building the project from scratch also helped me improve my understanding of:

- Semantic structure
- Sections
- Containers
- Images
- Headings
- Navigation
- Page organization
